# OTour 漫游引导 — 视觉识别

OTour 是分步漫游引导组件：全屏遮罩上为目标区域开一个圆角镂空"聚光灯"，旁边弹出引导卡片（图片/标题/详情 + 指示器 + 上一步/下一步按钮）。支持多步引导、非模态（无遮罩）模式、无目标居中展示与步骤图片箭头取色。@since v1.2.7

📱 **响应式行为**：
- 视口 ≤840px（phone / pad_v）时不渲染引导卡片与遮罩（避免遮挡小屏内容），回到宽屏自动恢复
- 引导卡片宽度跟随栅格变量：普通卡片 `--o-r-grid-6`、无目标居中卡片 `--o-r-grid-10`，随断点自动缩放
- 无目标（居中）模式、非遮罩模式有独立的紧凑化样式（内边距与字号缩小）

🧩 **布局结构**：Teleport 到 wrapper 的全屏容器（`.o-tour`）内含两层——SVG 遮罩层（`.o-tour-mask`，evenodd 填充在目标处挖出圆角镂空）和 OPopup 引导卡片（`.o-tour-popup`，12px 偏移指向目标，可带箭头）。卡片内部：右上关闭按钮、左侧图区（可选）+ 右侧内容区（标题/详情）、底部行（跳过区 + 步骤指示器 + 上一步/下一步按钮）。
```yaml
# 简化结构摘要（完整版见 Part B）
tour(全屏容器):
  - mask(SVG 遮罩，目标处镂空)
  - popup(引导卡片):
      - close(右上角)
      - content: [left 插槽, img(可选), title, detail]
      - footer: [skip 插槽, indicators(current/total), prev/next 按钮]
```

### 设计稿识别指南

**视觉特征指纹**

1. 整页半透明黑色遮罩，中间有一个**圆角矩形镂空**高亮当前操作区域（镂空与目标间有 12px 空隙、默认 4px 圆角）
2. 镂空旁弹出一张浅色圆角卡片，与镂空之间有指向箭头
3. 卡片右上角关闭图标；内部为标题 + 详情两行文本
4. 卡片底部左侧"第 n/m 步"指示器，右侧"上一步 / 下一步"按钮组（下一步为胶囊实心主色按钮）
5. 带图片的步骤：卡片左侧为图片区、右侧为文字区
6. 无遮罩变体：无全屏变暗，卡片独立浮在页面上（内边距更紧凑）

**设计 Token → Prop 值映射表**

| 设计特征 | Token / 视觉值 | Prop | Prop 值 |
|---------|---------------|------|--------|
| 页面遮罩变暗 | rgba(0,0,0,0.5) 遮罩 | `mask` | `true`（默认） |
| 无遮罩浮层 | 页面不变暗 | `mask` | `false` |
| 卡片在目标上方 | 箭头朝下 | `position` | `"top"` |
| 卡片在目标下方 | 箭头朝上 | `position` | `"bottom"`（默认） |
| 卡片在目标右侧 | 箭头朝左 | `position` | `"right"` / `"rt"` / `"rb"` |
| 卡片在目标左侧 | 箭头朝右 | `position` | `"left"` / `"lt"` / `"lb"` |
| 镂空圆角为胶囊形 | 镂空短边一半 | `spotlightRadius` | `"pill"` |
| 镂空圆角自定义 | 如 8px | `spotlightRadius` | `"8px"` 等任意 CSS 长度 |
| 隐藏箭头 | 卡片无指向三角 | `showArrow` | `false` |
| 无关闭按钮 | 卡片右上角无图标 | `showClose` | `false` |
| 视口居中卡片（无指向） | 卡片在屏幕中央、无镂空 | OTourStep `target` | 不传/`null` |
| 带图步骤 | 卡片左图右文 | OTourStep `img` | 图片 URL |

**易混淆组件区分表**

| 对比组件 | 相似点 | 区分方法 |
|---------|-------|---------|
| OPopover / OTooltip | 都是带箭头浮层指向目标 | Popover/Tooltip 是局部浮层无全屏遮罩；Tour 有全屏遮罩镂空 + 分步切换（上一步/下一步） |
| ODialog | 都有遮罩 | Dialog 是居中内容弹窗、无目标指向；Tour 遮罩上有镂空聚光、卡片贴着目标元素弹出 |
| OCarousel | 都有"n/m"切换指示 | Carousel 轮播页面内大图；Tour 引导卡片 + 遮罩镂空，切换的是引导步骤 |
